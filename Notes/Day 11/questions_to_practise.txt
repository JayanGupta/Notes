PYTHON PRACTICE QUESTIONS

========================
IF-ELSE (BASIC → MEDIUM)
========================

1. Write a program to check whether a given number is positive, negative, or zero.

2. Write a program to check whether a given number is even or odd.

3. Write a program to check whether a person is eligible to vote based on their age.

4. Write a program to find the greatest of two numbers entered by the user.

5. Write a program to find the greatest of three numbers using if-else.

6. Write a program to check whether a given year is a leap year or not.

7. Write a program to calculate electricity bill based on the following rules:

   * Units <= 100: ₹2 per unit
   * Units <= 200: ₹3 per unit
   * Units > 200: ₹5 per unit

8. Write a program to check whether a given character is a vowel or a consonant.

9. Write a program to check whether a number lies within a given range (inclusive).

10. Write a program to calculate the grade of a student based on marks:

    * > = 90: A
    * > = 75: B
    * > = 60: C
    * < 60: D
