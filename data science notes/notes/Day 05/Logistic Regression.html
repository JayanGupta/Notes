02 Linear Failure Framework

Fitting a standard linear prediction equation ($y = w \cdot x + b$) directly over binary markers causes issues:

  • Extrapolated Bounds: Calculating scores past the training parameters scales predictions beyond logical limits ($\hat{y} > 1$ or $\hat{y} < 0$).
  • Vulnerable Centers: Modulating extreme inputs alters the regression pitch, causing errors on internal points.

Watch how the regression line struggles to map binary coordinates accurately on the grid graph.

03 Sigmoid Transformation

To contain predictions within probability limits, we route the linear formula through the **Sigmoid Activation function**:

$$\sigma(z) = \frac{1}{1 + e^{-z}} \quad \text{where} \quad z = w \cdot x + b$$

This mathematical operation compresses the linear equation's infinite scale into a clean probability profile bounded between $0$ and $1$.

Formula Evaluation:p = 1 / (1 + e^-(w·x + b))

04 Binary Cross-Entropy Cost

We measure error by calculating the logarithm of our predictions relative to their true coordinates:

$$\text{Loss} = - [y \ln(p) + (1-y)\ln(1-p)]$$
  • If target $y = 1$, the penalty scales up exponentially as $p \to 0$.
  • If target $y = 0$, the penalty scales up exponentially as $p \to 1$.

05 Parameter Gradient Mechanics

To optimize our model, we take partial derivatives of the cost function to determine how changes to weights ($w$) or bias ($b$) impact overall error:

$$\frac{\partial J}{\partial w} = \frac{1}{m}\sum_{i=1}^{m}(p^{(i)} - y^{(i)})x^{(i)}$$

This tells us exactly how much a point's error, multiplied by its input coordinate, pulls our model parameters out of alignment.

Sample Derivative Computation Block:
Given a single test point at $x = 1.0, y = 1.0$
Current Model Probability Output: p = 0.731
Coordinate Prediction Variance: $(p - y) = 0.731 - 1.0 = \mathbf{-0.269}$
Weight Gradient Contribution: $(p - y) \cdot x = -0.269 \cdot 1.0 = \mathbf{-0.269}$
Result: A negative gradient directs the model to increase weight 'w', sharpening the curve to fit the data points.

07 Decision Boundary Sweeping

Models produce continuous probabilities. We apply an explicit threshold cutoff ($\tau$) to convert these probabilities into final classifications:

$$\hat{y} = 1 \quad \text{if} \quad p \geq \tau \quad \text{else} \quad 0$$
