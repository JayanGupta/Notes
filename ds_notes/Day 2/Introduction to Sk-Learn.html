Introduction to Scikit-Learn

The Industry Standard toolkit for Machine Learning in Python.

What is Scikit-Learn?

Scikit-Learn (or sklearn) is the most robust and accessible machine learning library in Python.

The Core Benefits:

  • Built on Giants: Built upon NumPy, SciPy, and Matplotlib. It integrates perfectly with Pandas.
  • Incredible Documentation: Widely considered to have the best documentation of any open-source library.
  • Battery Included: Contains algorithms for Classification, Regression, Clustering, and Preprocessing.

The Ultimate Consistency

The greatest strength of Scikit-Learn is its Uniform API. Whether you are building a simple linear line or a complex Random Forest, the code structure is exactly the same.

from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)
predictions = model.predict(X_test)

Features vs. Target Variables

Before computing math, your tabular records must be split into structural dimensions:

  • Features (Matrix $X$): The independent input variables or measurements used to make predictions. (Shape: [n_samples, n_features])
  • Target (Vector $y$): The dependent ground-truth label or real outcome you want the system to learn to forecast. (Shape: [n_samples])

Supervised vs. Unsupervised Learning

Machine learning tasks split cleanly into two fundamental paradigm environments:

  • Supervised Learning: The training data includes the target labels ($y$). The model learns mapping functions to separate explicit targets.
  • Unsupervised Learning: The training data has NO labels ($y$). The model must search for hidden structures and native geometric patterns on its own.

Toggle between paradigms to visualize how models treat labeled clusters vs. discovering structure organically.

The Estimator API

Every algorithm in Scikit-Learn follows the same uniform three-step process:

  1. Initialize: Set up the model model = Algorithm()
  2. Fit: The model learns from the data using .fit(X, y)
  3. Predict: The model guesses new outcomes using .predict(new_X)

Execute the code in the playground to watch the API in action.

Preprocessing: Scaling

Machine Learning algorithms rely on mathematical distances. If one feature is measured in millions (e.g., Salary) and another in single digits (e.g., Age), the algorithm will be biased toward the larger numbers.

StandardScaler: Modifies the data so it has a Mean of 0 and a Standard Deviation of 1.

Model Evaluation: Train/Test Split

We never evaluate a model on the same data we used to train it. That would be like giving a student the answer key before a test.

train_test_split() randomly divides our data into a Training set (to learn) and a Testing set (to evaluate).

Adjust the training size. Notice how a lack of training data (under 30%) causes the model to draw wildly inaccurate conclusions.

Overfitting vs. Underfitting

Finding the right sweet spot in machine learning model complexity is a key optimization objective:

  • Underfitting: Model is too simple. High bias. Fails to learn patterns in training data.
  • Overfitting: Model is too complex. High variance. Memorizes noise, failing completely on new test values.

The Scikit-Learn Ecosystem

1. Estimators (Models)

The algorithms that learn from data and make predictions.

  • LinearRegression()
  • RandomForestClassifier()
  • KMeans()
  • Core Methods: fit(), predict()

2. Transformers (Prep)

Tools used to clean, scale, and manipulate raw data before modeling.

  • StandardScaler()
  • OneHotEncoder()
  • SimpleImputer()
  • Core Methods: fit(), transform()

3. Meta-Tools

Utilities for combining steps and fine-tuning your model's performance.

  • Pipeline() (Chains steps)
  • GridSearchCV() (Finds best settings)
  • cross_val_score() (Validation)
